# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability in OBIX CONFIG LAB, please do not disclose the details publicly through GitHub Issues or other public channels.

Please report the issue privately to the project owner through the official OBIX CONFIG LAB contact channel, including:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected page, feature, or component
- Any relevant logs, screenshots, or proof of concept
- The potential impact, if known

## Scope

This policy applies to the original OBIX CONFIG LAB application and its project infrastructure under the control of the project owner.

Third-party libraries, frameworks, hosting platforms, and external services are governed by their respective security policies.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a security issue.

Thank you for helping keep OBIX CONFIG LAB and its users safe.
