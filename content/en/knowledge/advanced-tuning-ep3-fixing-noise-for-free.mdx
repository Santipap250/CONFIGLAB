Now that you know what noise is and where it comes from, the most common
question is: do I need to buy anything? The answer is that a lot of it
can be fixed immediately, for free.

## 1) Re-routing wires actually reduces noise

What to do: twist the battery leads tightly, keep high-current power
wires separated from signal wires, and don't let ESC wires run right past
the FC or gyro.

Clean wiring alone often makes noise drop noticeably right away.

## 2) Check the FC mount (don't over-tighten)

Bolting the FC down too hard sends frame vibration straight into the
gyro. Use grommets or a soft-mount, and don't crank the screws all the
way down — the FC needs to be steady, not rigid.

## 3) Props — the overlooked noise source

Chipped props, warped props, cheap unbalanced props — all of this is
mechanical noise that's genuinely hard for filters to clean up. Swapping
props alone makes some builds feel noticeably calmer, with no PID changes
at all.

## 4) Check the frame and every screw

Loose screws, a cracked frame, motors torqued unevenly — small things
like these make the gyro read incorrectly all the time. This matches step
one in the <a href="/tuning">Tuning Guide</a>, which puts a mechanical
check before anything else for exactly this reason.

## 5) Don't blame PID first

If the quad shakes, motors run hot, or PID adjustments aren't helping,
ask yourself first whether noise has actually been dealt with — see
<a href="/knowledge/pid-controller-basics">PID Controller Basics</a> for
more.

## The mindset experienced pilots actually use

> Fix noise first, then tune filters, and only then touch PID.

Doing it in the wrong order means tuning in circles that never resolve.

## EP3 summary

A lot of noise can be fixed for free. Build quality matters just as much
as software settings. Genuinely stable builds usually start from good
fundamentals.
