ข้อมูล gyro ทุกตัวมีทั้งข้อมูลการบินจริงและ noise เชิงกลปนกันอยู่ — การสั่น
ของมอเตอร์, ใบพัดไม่บาลานซ์, เฟรม resonance ฟิลเตอร์มีหน้าที่กำจัด noise
ออก เพื่อให้ PID loop ตอบสนองต่อตัวเครื่องจริง ไม่ใช่ต่อ noise floor

## Low-pass filters (LPF)

ฟิลเตอร์ low-pass ของ gyro และ D-term จะตัดทุกอย่างที่สูงกว่าความถี่ที่
กำหนดไว้ cutoff ต่ำ = สัญญาณเรียบขึ้นแต่มี latency (ดีเลย์) ใน control loop
มากขึ้น, cutoff สูง = ตอบสนองไวขึ้นแต่ noise ผ่านเข้ามาได้มากขึ้น ค่า
cutoff ที่เหมาะสมขึ้นกับขนาดใบพัด, KV มอเตอร์ และความแข็งของเฟรม — ไม่มี
ตัวเลขสากลตายตัว

## Dynamic notch filters

แทนที่จะใช้ cutoff คงที่ตัวเดียว dynamic notch filter จะติดตามความถี่ของ
noise หลักแบบ real-time (ปกติคือ harmonics ตามลำดับของมอเตอร์) แล้วเจาะ
ช่อง (notch) แคบๆ รอบความถี่นั้น โดยไม่แตะส่วนอื่นของสเปกตรัม นี่คือเหตุผล
ที่ KV มอเตอร์และขนาดใบพัดมีผลต่อการตั้งค่าช่วง notch — เพราะมันกำหนดว่า
noise อยู่ตรงไหนจริงๆ

## อ่านค่าใน blackbox

กราฟ gyro ที่สะอาดใน blackbox จะเป็นเส้นเรียบตามสติ๊กที่กดโดยไม่มีอาการ
"ฟู" หนาขึ้น ถ้ากราฟดูฟูหรือ "ขนดก" แปลว่า noise หลุดผ่านฟิลเตอร์เข้ามา
และจะไปโผล่เป็นความร้อนที่มอเตอร์และความหยาบใน PID response แม้ว่า P/I/D
จะ "ถูกต้อง" ในทางทฤษฎีก็ตาม

## ลำดับที่ควรทำจริง

1. เช็คว่าใบพัดบาลานซ์และมอเตอร์ไม่มีปัญหาเชิงกล — ฟิลเตอร์แก้แกนคดไม่ได้
2. ตั้งช่วง dynamic notch จาก KV มอเตอร์ / ขนาดใบพัด
3. ตั้ง LPF cutoff แบบระมัดระวังก่อน แล้วค่อยๆ ปรับให้แคบลงพร้อมดู
   blackbox และอุณหภูมิมอเตอร์
4. ค่อยไปต่อที่ P/I/D
