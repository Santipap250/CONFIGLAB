PID loop เดียวกันทำงานอยู่เบื้องหลังทุกโหมดการบิน — สิ่งที่เปลี่ยนไปคือ
สิ่งที่ FC ใช้เป็นเป้าหมายที่ loop จะแก้ไขเข้าหา

## Acro (rate mode)

ไม่มีการปรับระดับอัตโนมัติเลย สติ๊กจะแปลงตรงเป็น *อัตรา* การหมุน (ลำ
หมุนเร็วแค่ไหน) และเป็นหน้าที่ของนักบินทั้งหมดที่จะบินกลับมาระดับปกติเอง
นี่คือโหมดที่การบิน freestyle และ racing เกือบทั้งหมดใช้ เพราะทำให้ตี
ลังกา, roll และบินคว่ำได้เต็มรูปแบบ

## Angle mode

สติ๊กจะแปลงเป็น *มุม* เป้าหมาย — ปล่อยสติ๊กแล้ว FC จะปรับลำให้กลับมาที่
มุมนั้นเอง จนถึงค่า `angle_limit` ที่ตั้งไว้ แลกกับการเสียท่าผาดโผนเต็ม
รูปแบบ เพื่อให้เป็นโหมดที่ตกยากขึ้นโดยไม่ตั้งใจ จึงเป็นโหมดมาตรฐานสำหรับ
บินครั้งแรกของลำใหม่ หรือนักบินมือใหม่

## Horizon mode

ผสมกัน: ใกล้กลางสติ๊กจะทำตัวเหมือน Angle mode (ปรับระดับเอง) แต่เกิน
threshold หนึ่งจะค่อยๆ เปลี่ยนไปเป็นการตอบสนองแบบ Acro เมื่อกดสติ๊กสุด
ทำให้ตีลังกาและ roll ได้ ในขณะที่ยังปรับระดับเองเมื่อปล่อยสติ๊ก เป็นจุด
กึ่งกลาง ไม่ได้ "ดีกว่า" หรือ "แย่กว่า" อีกสองโหมดเสมอไป

## ทำไมเรื่องนี้ถึงสำคัญกับการจูน

ค่า PID ถูกจูนหลักๆ สำหรับการตอบสนองแบบ rate ของ Acro โหมด Angle และ
Horizon เพิ่มพฤติกรรมปรับระดับของตัวเองทับเข้าไป ควบคุมแยกต่างหากด้วย
`angle_limit` และค่าความแรงเฉพาะโหมด — ดังนั้นอาการกระตุกใน Angle mode
ไม่ได้แปลว่าเป็นปัญหา PID ในทูน rate หลักเสมอไป
