การตั้งค่า Betaflight ครั้งแรกของลำใหม่มีลำดับตามธรรมชาติของมัน — การ
ข้ามขั้นตอนมักหมายถึงต้องย้อนกลับมาทำขั้นก่อนหน้าใหม่เมื่อมีอะไรทำงาน
ผิดปกติ

## 1. Firmware และ Ports

แฟลช firmware target ที่ถูกต้องสำหรับ flight controller ของคุณก่อน แล้ว
ตั้งค่า ports (การกำหนด UART ให้ตัวรับ, VTX และอุปกรณ์ต่อพ่วงอื่นๆ) ก่อน
แตะอะไรอย่างอื่น — ทุกอย่างที่ตามมาจะทำงานไม่ได้ถ้าขั้นนี้ไม่ถูกต้อง

## 2. ตัวรับสัญญาณ (Receiver)

ตั้งค่า `serialrx_provider` ให้ตรงกับ protocol ของตัวรับ, bind มัน และ
เช็คว่าแต่ละ channel ขยับถูกต้องในแท็บ Receiver

## 3. โหมดการบิน

กำหนดสวิตช์ arm และอย่างน้อยหนึ่งโหมดการบิน (Angle เป็นตัวเลือกมาตรฐาน
อันดับแรก) ให้กับสวิตช์ ก่อนเปิดเครื่องครั้งแรกโดยใส่ใบพัด

## 4. ทิศทางมอเตอร์และ Mixer

ถอดใบพัดออกก่อน แล้วเช็คว่าแต่ละมอเตอร์หมุนทิศทางถูกต้องตาม mixer และ
ทิศทางใบพัดของคุณ และลำดับมอเตอร์ตรงกับผังใน configurator — เรื่องนี้
สำคัญด้านความปลอดภัย ไม่ใช่แค่ความชอบเรื่องจูน

## 5. Failsafe

ตั้งค่าและทดสอบขั้นตอน failsafe บนโต๊ะโดยถอดใบพัดออก ก่อนจะ arm โดยใส่
ใบพัดทุกครั้ง ดู <em>Radio Link &amp; Failsafe</em> ใน Knowledge Hub ว่า
ควรทดสอบอะไรบ้าง

## 6. ค่า Default สำหรับบินครั้งแรก

บินครั้งแรกด้วยค่า PID และฟิลเตอร์ที่ใกล้เคียง default ในโหมด Angle ใน
พื้นที่โล่ง และบันทึกล็อกไว้ — กระบวนการของ Tuning Guide เริ่มต้นจาก
blackbox log แรกนั้น ไม่ใช่จากค่า default เพียงอย่างเดียว
